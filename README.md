# Stranger Things Bootstrap

Proyecto web estatico inspirado en Stranger Things, construido con HTML y CSS.

## Estructura

- `index.html`
- `style.css`
- `img/`

## Vista previa local

Abre `index.html` en tu navegador.

## Publicar en GitHub

1. Inicializa Git (si aun no esta inicializado):
   ```bash
   git init
   ```
2. Crea la rama principal:
   ```bash
   git branch -M main
   ```
3. Agrega y confirma cambios:
   ```bash
   git add .
   git commit -m "Initial commit"
   ```
4. Crea un repositorio vacio en GitHub y conecta remoto:
   ```bash
   git remote add origin https://github.com/TU_USUARIO/TU_REPO.git
   git push -u origin main
   ```
